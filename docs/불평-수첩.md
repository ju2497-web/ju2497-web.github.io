# 불평 수첩 (2026-10-29 시작)

목적: 사람들이 반복해서 짜증 내거나 불신하는 지점을 모은다. 다음 상품, 블로그 글, 쇼츠 주제는 여기서 고른다(TrustMRR 영상 판정, 2026-10-29: 사이트는 "가짜 매출 캡처가 넘쳐난다"는 불평 한 줄에서 시작했다).

## 규칙

- 출처를 꼭 적는다(숨고 요청, 블로그 댓글, 대학원생 질문, 학부모 커뮤니티, 뉴스 댓글 등). 지어내지 않는다.
- 개인을 알아볼 수 있는 내용은 적지 않는다.
- 불평뿐 아니라 **사람들이 시키지 않아도 자기 숫자를 적어 올리며 묻는 질문**("공복혈당 108인데 괜찮나요?")도 적는다. 가장 강한 수요 신호다(2026-10-30, 키 예측 앱 영상 판정).
- 같은 불평이 3번 나오면 '반복' 칸에 표시하고, 상품이나 글로 만들지 검토한다.
