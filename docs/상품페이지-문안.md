# 숨고·크몽 상품 페이지 문안 (2026-10-12 가격 기준)

규칙: 연락처·외부 링크 없음(두 플랫폼 정책). 합격 보장·100%·최고 같은 표현 없음. **입학처장 직함은 쓰되 소속 대학명은 쓰지 않음**(2026-10-13 교수님 결정). 숫자는 `js/coach/config.js`와 반드시 같게 유지.

## 1. 상품 제목(크몽 60자 이내)
현직 입학처장 교수가 면접관의 눈으로 만드는 대입 면접 답변 노트 (공개 문항 전체 + 꼬리질문)

## 2. 한 줄 소개(숨고 프로필 상단)
현직 입학처장 교수가, 대학이 공개한 면접 문항 전체에 대해 학생 본인의 실제 경험으로 답변·꼬리질문·말하기 대본을 만들어 드립니다.

## 3. 상품 설명(본문)

**누가 만드나요**
보건계열 현직 대학교수이자 입학처장입니다(소속 대학명은 밝히지 않습니다). 입학처장으로 면접 평가를 운영하고 참여해 왔고, 면접관이 각 질문에서 무엇을 보는지(평가 의도, 평가 역량, 감점 요인)를 기준으로 답변을 만듭니다. 글을 잘 쓰는 사람이 아니라 평가하는 사람이 만든다는 점이 다릅니다.

**무엇을 받나요**
대학이 공개한 면접 문항 전체에 대해 문항마다
1. 질문의 평가 의도(면접관이 실제로 보는 것)
2. 학생 본인의 실제 경험으로 만든 답변(45~55초 분량)
3. 예상 꼬리질문 3개와 대응 방향
4. (정밀형 이상) 말하기 대본, 핵심 키워드, 연습 포인트, 교수 총평

**어떻게 진행되나요**
결제 확인 → 채팅으로 7가지 자료 양식 전달(약 5분, 문장이 아니라 있었던 일만 적으면 됩니다) → 자료 접수 후 48시간 안에 답변 노트 전달 → (패키지) 줌 모의면접 30분 일정 조율.
함께 드리는 앱 이용 코드로 면접일까지 공개 문항을 직접 입력해 예상 점수·감점 요인·꼬리질문을 반복 확인할 수 있습니다.

**가격**
| 상품 | 가격 | 구성 |
|---|---|---|
| 간편형 | 29,000원 | 공개문항 전체 답변 + 질문 의도 + 꼬리질문 3개 + 앱 이용 코드 |
| 정밀형 | 49,000원 | 간편형 + 학생부 반영 + 말하기 대본·연습 포인트 + 교수 총평 |
| 실전 패키지 (추천) | 79,000원 | 정밀형 + 줌 모의면접 30분 (따로 하면 89,000원) |
| 줌 모의면접 단품 | 40,000원 | 30분, 실제 면접처럼 질문·꼬리질문 후 바로 피드백 |

**지키는 것**
- 학생이 적어 준 사실만 씁니다. 없는 경험을 만들어 넣지 않습니다.
- 출신 학교명·가족 직업·이름이 들어가면 블라인드 면접 위반이므로 걸러 드립니다.
- 합격 여부는 대학이 결정하므로 보장하지 않습니다. 대신 면접관이 보는 기준에 맞게 본인 경험이 가장 잘 드러나도록 만듭니다.
- 이해충돌 방지를 위해 제 소속 대학 지원자는 받지 않습니다.
- 무료 샘플은 드리지 않습니다. 본인 경험이 없는 샘플은 누구에게나 맞는 일반론이 되어 판단에 도움이 되지 않기 때문입니다.

## 4. 자주 묻는 질문(상품 페이지용)
- **문항이 몇 개까지 되나요?** 대학이 공개한 문항 전체입니다. 보통 5~8문항이고, 10개를 넘으면 미리 말씀드리고 범위를 함께 정합니다.
- **특별한 활동이 없는데 괜찮나요?** 괜찮습니다. 활동의 크기보다 평범한 경험을 얼마나 구체적으로 말하는지가 더 중요합니다. 조별과제, 수업 중 탐구, 친구와의 갈등도 좋은 답변이 됩니다.
- **학생부 없이도 되나요?** 간편형은 공개 문항과 직접 적어 주신 경험만으로 진행합니다. 학생부까지 반영하려면 정밀형을 권합니다.
- **답변을 그대로 외워도 되나요?** 통째로 외우면 오히려 어색해집니다. 키워드와 말하기 대본을 함께 드리니 키워드만 보고 자기 말로 하는 연습을 권합니다.
- **얼마나 걸리나요?** 자료 접수 후 48시간 안에 전달합니다. 면접일이 가까우면 먼저 말씀해 주세요.

## 5. 썸네일 문구(3안)
1. 면접관이 보는 것 ≠ 학생이 쓰는 것
2. 현직 입학처장이 면접관의 눈으로 만든 답변 노트
3. 공개 문항 전체 + 꼬리질문 3개 + 48시간

## 6. 숨고 서비스 소개(짧은 글, 500자 이내)
입학처장으로 대학 면접 평가를 운영하고 참여해 온 보건계열 현직 교수입니다. 대학이 공개한 면접 문항 전체에 대해 질문의 평가 의도를 먼저 분석하고, 학생 본인의 실제 경험으로 45~55초 답변과 예상 꼬리질문 3개를 만들어 드립니다. 글을 잘 쓸 필요 없이 있었던 일만 적어 주시면 되고, 자료 접수 후 48시간 안에 전달합니다. 허위 경험은 넣지 않고, 합격을 보장하지 않으며, 제 소속 대학 지원자는 받지 않습니다. 간편형 29,000원, 정밀형 49,000원, 줌 모의면접을 더한 실전 패키지 79,000원입니다.
