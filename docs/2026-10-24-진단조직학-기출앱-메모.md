# 진단조직학 기출 마스터 (`histo/`) 메모

- 결정일: 2026-10-24, 교수님 지시 "수익이 되는 앱 만들어줘".
- 주소: `https://ju2497-web.github.io/histo/` (main에 합쳐진 뒤 동작). 관리 화면 `histo/admin.html`.
- 왜 이 앱인가: 아크포인트 메모(2026-10-12)의 네 질문에 답이 되는 유일한 후보였다.

| 질문 | 답 |
|---|---|
| 쓰이는가 | 임상병리사 국가시험 응시자는 매년 수천 명이고, 교수님 수업의 학생이 첫 사용자다. 원본 문서에 이미 "앱 출제 제외" 표시가 있었다. 교수님이 앱을 전제로 문항을 검증해 두셨다는 뜻이다 |
| 돈이 나는가 | 이용권 판매(하드 페이월, 면접 코치와 같은 이용 코드 방식). 종이 문제집 한 권 값 |
| 병목을 없앴는가 | 문제집 인쇄·배포·개정 없이 문항을 고치면 바로 반영된다. 학생은 오답만 다시 푼다 |
| AI 네이티브인가 | 아니다. 그러나 이 앱은 AI가 아니라 **검증된 기출 530문항과 교수의 해설**이 자산이다. 지식 덤핑 방지 규칙(정리 6)과도 맞는다. AI는 쓰지 않는다 |

## 무엇을 만들었나
- 문항 데이터: 필기 321(정답 없는 1996 Q20 제외), 실기 149(사진 없음·원문 대조 전 5건 제외), 부록 판독 60(1건 제외). 사진 209장. 검증 상태·표기 교정 같은 내부 정보는 뺐다. 문제집(2026-10-22)과 같은 원천이다.
- 기능: 챕터별 핵심정리·주의 함정·출제패턴 → 필기 → 실기(사진) 순서로 풀기, 고른 즉시 정답·사진 판독·해설·필기 연계 표시, 안 푼 문항부터, 필기만·실기만, 모의고사 20문항(필기 6 : 실기 4, 무작위), 오답노트(틀린 횟수 기준, 맞히면 빠짐), 반복 출제 개념 18, 진도·정답률. 진도는 기기(localStorage)에만 저장.
- 페이월: Chapter 1 무료(`freeChapters`), 나머지와 모의고사는 이용 코드. 코드 해시만 저장소에 둔다(면접 코치와 같은 방식). 결제 링크는 비어 있다.
- 집계: `config.js`의 goatcounter 또는 ga4를 넣으면 챕터 진입·페이월 노출·모의고사·결과 이벤트가 기록된다.
- 검증: 헤드리스 브라우저로 홈 → Chapter 1 → 실기 풀기 → 정답 표시 → 잠긴 챕터 페이월 → 잘못된 코드 거부 → 반복 개념표까지 확인했다. 콘솔 오류 없음.

## 교수님 결정 사항(이것이 없으면 수익은 0원)
1. **가격**: 14,900원(임시). 기간 "국가시험일까지".
2. **무료 범위**: Chapter 1만 무료. 면접 코치의 "무료 없음" 원칙과 다르게 둔 이유는 국가시험 문제집은 샘플 챕터가 구매 기준이기 때문이다. 원하시면 `freeChapters: []`.
3. **판매 채널**: 크몽 디지털 상품 또는 스마트스토어 링크를 `payLinks`에 넣는다. 결제 확인 → `admin.html`에서 코드 생성 → 해시를 `config.js`에 추가해 배포 → 학생에게 코드 전달. 면접 코치와 같은 흐름.
4. **배포 채널**: 교수님 수업(첫 사용자), 임상병리사 국시 준비 커뮤니티, 전국 임상병리학과 교수 네트워크. 지인 비이용 원칙은 입시 사업의 원칙이며, 이 앱은 교수님 전공 교육 활동이라 교수님이 따로 정한다.
5. **소속 학생 판매 여부**: **2026-10-24 교수님 결정: 모든 사람에게 판다(소속 학생 포함).** 앱은 처음부터 누구나 같은 조건으로 쓰도록 되어 있으므로 바꿀 것은 없다. 소속 학생에게 수업 교재로 쓰게 할 때 대학의 교재 판매 규정 확인은 교수님 몫으로 남긴다.
6. **저작권 확인**: 기출 문항·사진은 국가시험원 공개 문항이다. 상업적 이용 조건을 국시원 공개 자료 이용 안내에서 확인한다. 참고 사진 4건(CC BY)은 출처를 표시했다.
7. **집계 코드**: `config.js`의 goatcounter 사이트 코드(실험실과 같은 계정이면 같은 코드). 없으면 몇 명이 쓰는지 알 수 없다.

## 다음 단계
- 교수님이 1~3을 정하면 상품 페이지 문안(크몽·스마트스토어)을 쓴다. 상품 설명은 "현직 교수가 1983~2025 기출을 검증, 사진 문항 209장, 틀린 문제만 다시" 세 줄이 핵심이다.
- 문항 수정은 `histo/data/questions.json`을 직접 고치지 않고, 원본 문서를 고친 뒤 다시 생성한다(생성 코드는 세션 작업 폴더에 있었으므로 필요하면 다시 만든다).

## 2026-10-26 공개 저장소에서 내림
- 이유: 국시원 출제문제를 복원해 기출문제집으로 판매한 출판업자 3명이 저작권법 위반으로 벌금형을 받은 판례가 있다(의사·간호사 국가시험, 서울동부지법, 의협신문·의학신문 보도). 법원은 수험생 기억으로 복원한 문제나 일부를 바꾼 문제도 복제로 보았다. 이 저장소는 공개 상태여서, 결제와 무관하게 `histo/data/questions.json`과 사진 209장을 누구나 내려받을 수 있었다. 페이월은 화면만 막고 데이터는 막지 못했다.
- 조치: `histo/` 폴더를 브랜치에서 삭제했다. 이전 커밋 기록에는 남아 있으므로 기록까지 지울지는 교수님 결정 사항이다.
- 앞으로: 기출 원문은 국시원의 이용 허락 없이 판매·공개하지 않는다. 교수님이 직접 만든 예상문제·해설·핵심정리는 교수님 저작물이므로 출판·판매할 수 있다. 판매 앱을 다시 만든다면 문항 데이터는 공개 저장소가 아니라 로그인 뒤에만 내려가는 서버에 둔다.
