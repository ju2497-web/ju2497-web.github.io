# 검수 사례 전·후 비교 템플릿 (무료 샘플 대신 보여 주는 자료)

용도: 숨고·크몽 포트폴리오, 릴스 본문, 상담 채팅. 실제 학생 사례는 **본인 동의**를 받고, 학교명·이름·대학명·학과가 특정되는 정보를 지운 뒤에만 쓴다. 아래 예시는 앱의 내장 예시 데이터로 만든 **가상 사례**이며 실제 학생이 아니다. 실제 사례가 3건 모이면 이 가상 예시는 삭제한다.

## 작성 규칙
- 문항은 "공개 문항 유형"으로만 적는다(예: 갈등 해결 유형). 대학이 특정되는 문장은 바꾼다.
- 전(학생이 처음 쓴 것)은 2~3문장만, 후(완성 답변)는 45~55초 분량 그대로.
- 점수는 앱의 예상 점수(연습용 지표)라고 명시한다.
- 바뀐 점은 평가 항목 이름으로 적는다(구체성, 두괄식, 성찰, 전공 연결).

## 가상 예시 1 (앱 내장 예시 데이터, 실제 학생 아님)

**문항 유형**: 갈등 해결(공동체 역량)
**학생 상황**: 고2, 보건계열 희망, 모둠 탐구 활동 경험

**전(학생 초안, 예상 39점)**
> 친구와 의견 차이가 있었지만 대화를 통해 잘 해결했습니다. 이 경험을 통해 소통의 중요성을 배웠고, 앞으로도 소통을 잘하는 사람이 되겠습니다.

**후(완성 답변, 예상 94점)**
> 저는 갈등이 생기면 먼저 상대가 왜 그렇게 생각하는지부터 들으려고 합니다. 모둠 탐구에서 역할 분담을 두고 친구와 의견이 달랐던 적이 있습니다. 상대방 입장을 이해하기 위해 저는 따로 만나 이유를 물어보니 발표 경험이 없어 부담스러워했습니다. 그래서 친구가 잘하는 포스터 디자인을 맡기고 자료 조사는 함께 하자고 제안했습니다. 그 결과 캠페인을 기한 안에 마무리했습니다. 이 경험으로 행동만 보고 판단하기 전에 사정을 먼저 묻는 것이 해결의 첫걸음이라는 것을 배웠습니다. 간호사가 되어서도 환자와 동료의 입장을 먼저 헤아리겠습니다.

**바뀐 점 3가지**
1. 두괄식: 첫 문장이 "저는 ~합니다"라는 결론으로 바뀜.
2. 구체성: "대화했다"가 "따로 만나 이유를 물었다 → 역할을 바꾸자고 제안했다 → 기한 안에 마무리했다"로 바뀜.
3. 전공 연결: 배운 점이 간호 현장의 태도로 이어짐.

**꼬리질문 대비**: "이야기를 나눴는데도 상대가 바뀌지 않았다면요?" → 한 번 더 대안을 제시하고, 그래도 어려우면 선생님께 조정을 부탁하되 상대를 탓하지 않는다.
