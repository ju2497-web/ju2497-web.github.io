# 수입 실행 계획 (2026-10-14)

지금까지의 판단 기록(`docs/` 전체)을 "이번 달에 실제로 돈이 들어오는 순서"로 다시 정리한 것입니다. 원칙은 하나입니다. **이미 돈이 들어온 곳에 시간을 몰고, 아직 증거가 없는 곳은 멈춘다.**

## 지금까지의 증거
| 채널 | 결과 | 판단 |
|---|---|---|
| 숨고 논문 컨설팅 | 열흘간 고용 5건, 리뷰 6건(전부 5.0) | **유일하게 검증된 수입원.** 여기에 집중 |
| 숨고 대입 면접 | 요청 40건, 견적 10건, 고용 0건, 캐시 10만 원 이상 소진 | 돈이 나가기만 함. 신규 견적 중단 |
| 면접 앱(셀프 19,900) | 판매 기록 없음 | 더 만들지 않음 |
| 참고 영상 판정 | 이틀간 7편, 실제 수입으로 이어진 것 없음 | 당분간 영상 보는 시간을 지원·응대 시간으로 |

## 1순위: 숨고 논문 컨설팅 (이번 주부터)
1. **견적 캐시는 논문에만 씁니다.** 면접 요청은 이미 진행 중인 2건만 마무리하고 새 견적은 보내지 않습니다.
2. **요청이 오면 30분 안에 견적을 보냅니다.** 화면을 올려 주시면 Claude가 바로 문안을 씁니다(숨고 응답기).
3. **정밀진단 가격은 지금 바꾸지 않습니다.** 150,000원을 권고했었지만, 현재 가격으로 고용이 나오고 있으므로 돈이 급한 지금은 흐름을 끊지 않습니다. 리뷰가 15건을 넘으면 다시 봅니다.
4. **진단 1건을 다음 상품으로 잇습니다.** 이것이 가장 큰 지렛대입니다. 석사 전 과정 1건(300만 원)이 정밀진단 30건과 같습니다. 진단 리포트 마지막에 "다음 단계 제안"(부분 컨설팅·심사 대응·전 과정 중 하나, 금액과 기간 포함)을 반드시 넣습니다. 논문진단 스킬로 리포트를 만들 때 이 절을 함께 씁니다.
5. **이미 고용한 5명에게 다음 단계를 묻습니다.** 숨고 채팅으로 "심사 일정이 잡히셨으면 심사 의견 대응도 봐 드릴 수 있습니다" 한 줄. 공개 채널로 온 고객이므로 지인 비이용 원칙과 충돌하지 않습니다.

## 2순위: 크몽에 같은 논문 상품 등록 (이번 주 안)
새로 만들 것이 없습니다. `상품페이지-문안.md`와 숨고 상세 설명 수정본을 그대로 씁니다. 숨고와 다른 고객층(대학원생 검색 유입)이 있는 두 번째 시장입니다. 이미 등록했다면 건너뜁니다.

## 3순위: 해외 AI 전문가 평가 (달러 시급, 원격, 시간 선택)
- Mercor 같은 플랫폼이 의학·생물학 전문가에게 AI 답변 평가를 맡기고 시간당 달러로 지급합니다. 공개 공고 기준으로 생물학 박사 $60~100, 의사 면허가 필요한 의학 전문가 $130~300입니다(공고·시점마다 다름). 교수님은 박사이므로 앞쪽 범위가 현실적이고, 그것만으로도 교수님 기준 시급 65,000원보다 높습니다.
- 지원 → 테스트 → 배정까지 몇 주 걸리고, 탈락도 흔합니다. 그래서 1·2순위와 **동시에** 시작합니다.
- 하루 1건씩 지원합니다. "오늘 공고"라고 하시면 수입 탐색 스킬이 1건을 고르고, 지원 화면을 올리시면 AI SME 지원 스킬이 답변과 영문 이력서를 맞춥니다.
- 확인할 것: 해외 플랫폼 계약 업무가 총장에게 받은 겸직 승인 범위에 들어가는지 한 번 확인합니다.
