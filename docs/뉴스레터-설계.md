# 뉴스레터 「면접관의 눈」 설계안

- 대상: 대입 면접을 앞둔 학생과 학부모, 진로·진학 담당 교사, 면접 교육에 관심 있는 교육기관
- 약속: 매주 수요일 아침, 면접관이 실제로 보는 것 한 가지를 1분 안에 읽을 분량으로
- 보내는 사람 이름: 교수님 성함 + "현직 대학교수 · 입학처장". 소속 대학명은 쓰지 않는다(2026-10-13 교수님 결정: 직함은 쓰되 학교명은 쓰지 않고, 지인에게 묻지 않는다)
- 원칙: 소속 대학의 전형·문항 언급 금지, 합격 보장·과장 표현 금지, 실제 학생 사례는 동의 없이 쓰지 않음, 매출 비공개

## 1. 발행 계획(1~10호 = 블로그 글 10편)
본문은 `docs/블로그-글-10편.md`의 긴 글을 그대로 씁니다. 아래는 메일 제목과 미리보기 문장입니다. 제목은 열어 보게 하는 문장, 미리보기는 제목 옆에 작게 보이는 한 줄입니다.

| 호 | 메일 제목 | 미리보기 문장 |
|---|---|---|
| 1 | 면접관은 답변을 끝까지 듣지 않습니다 | 첫 10초에 결정되는 두 가지, 그리고 오늘 고칠 첫 문장 |
| 2 | "어릴 때부터 꿈이었습니다"가 감점인 이유 | 지원 동기는 계기 → 확인 → 행동, 세 문장이면 됩니다 |
| 3 | "대화로 잘 해결했습니다"는 답이 아닙니다 | 갈등 질문의 평가표에는 네 칸이 있습니다 |
| 4 | "참았습니다"가 돌봄 계열 면접에서 걱정을 사는 이유 | 참을성이 아니라 가라앉힌 방법을 봅니다 |
| 5 | 역량 세 개를 말하면 면접관은 하나도 믿지 않습니다 | 역량 하나, 업무 장면 하나, 내 습관 하나 |
| 6 | "많은 것을 배웠습니다" 다음에 면접관이 되묻는 말 | 세특 활동 답변에 꼭 들어가야 할 네 가지 |
| 7 | 면접관이 하루에 열 번 듣는 단점, 완벽주의 | 단점 뒤에 붙여야 하는 세 글자 |
| 8 | "열심히 해서 올렸습니다"에 없는 것 | 원인 → 방법의 변화 → 결과 |
| 9 | 윤리 문항에는 정답이 없고 순서가 있습니다 | 가치 → 보고 → 안전 → 재발 방지 |
| 10 | "훌륭한 간호사가 되겠습니다"에는 계획이 없습니다 | 과목 이름과 시점으로 말하는 학업 계획 |

## 2. 매 호 공통 구조
1. 첫 두 줄: 이번 주 질문 유형과 흔한 답변 한 문장(블로그 글의 훅)
2. 본문: 블로그 글 그대로(600~900자)
3. 이번 주에 해 볼 것: 한 가지 행동(블로그 글의 "고치는 법")
4. 답장 유도: "이번 주 문항으로 쓴 첫 문장을 답장으로 보내 주시면 다음 호에서 몇 개를 골라 고쳐 드립니다(이름·학교는 지웁니다)." 영상의 "질문에 성실히 답하기"를 구조로 만든 것. 답장이 다음 호의 재료가 된다.
5. 안내 한 줄(고정): "대학이 공개한 면접 문항으로 본인 답변을 만드는 서비스와, 고교·교사 연수·학부모 교육 특강 문의는 프로필을 보세요." 링크는 숨고 프로필 또는 안내 페이지.

## 3. 구독 유도 문구(붙여 넣기용)
- 블로그 글 끝: "이 글은 매주 수요일 이메일로도 보냅니다. 면접관이 실제로 보는 것 한 가지, 1분 분량. (구독 링크)"
- 스레드 프로필: "현직 입학처장 교수가 쓰는 면접관의 눈. 매주 수요일 메일 한 통."
- 숨고·크몽 상품 설명 끝(링크 금지이므로 문구만): "매주 수요일 '면접관의 눈' 뉴스레터를 보내고 있습니다. 검색하시면 구독할 수 있습니다."
- 앱 결제 창·전달 안내: 구독 링크 한 줄(코드와 함께 보내는 전달 메시지에 추가 가능)

## 4. 발행 전 체크리스트
- [ ] 플랫폼 가입(메일리 또는 스티비), 발신자 이름·답장 주소 설정
- [ ] 구독 페이지에 약속 한 줄(매주 수요일, 1분, 면접관이 보는 것 하나)과 하지 않는 것 세 가지(허위 경험·소속 대학 지원자·무료 샘플)
- [ ] 1호·2호 예약 발행, 3호부터 매주 수요일 오전 7시
- [ ] 블로그 글 끝과 스레드 프로필에 구독 링크
- [ ] `docs/뉴스레터-발행기록.md`에 호별 발송 수·열람률·클릭·구독 증감 기록(플랫폼 통계 화면에서 옮겨 적기)
- [ ] 구독자 1,000명 도달 시 첫 판매 메일 1통(그 전에는 안내 한 줄만)

## 5. 10호 이후
- 잘된 호(열람률·답장 수 기준 상위 3개)의 주제와 제목 방식으로 11~20호 주제를 정한다. 후보: 꼬리질문만 다루는 시리즈, 학부모가 하는 흔한 실수, 면접 당일 10분 전 체크, 블라인드 면접 금지어, 제시문 면접 읽는 순서. (2026-10-20 추가) AI가 써 준 면접 답변을 면접관은 어떻게 알아보는가: 이경전 교수 인터뷰 메모 2-3절.
- 답장으로 온 첫 문장을 고쳐 주는 코너가 반응이 좋으면 정규 코너로 승격한다. 이것이 영상의 "되는 데 집중"이다.
