# 검색 빈틈 공략 블로그 전략 (2026-10-29)

출발점: 교수님이 가져오신 '볼테어(Volteer)' 영상 요약. 구글 출신 개발자가 앱스토어 대신 구글 검색의 작은 질문들(롱테일 키워드)을 공략했다는 내용이다. 구글 서치 콘솔에서 "노출은 많은데 순위가 뒤라 클릭이 거의 없는 검색어"를 매일 하나 골라, Claude가 그 질문에 딱 맞는 글을 한 편씩 쓰게 했다. 영상은 보지 못했고(vidIQ 크레딧 0) 요약 기준으로 판단했다. 월 5,300만 원이라는 숫자는 확인하지 못했다.

## 판단: 한다. 우리 원칙과 같은 방향이다

- 대량 생산이 아니라 **하루 한 편, 수요가 확인된 질문 하나**다. "검색에 깔리는 글을 쌓는다"(Voicy 판정 2026-10-24), "알리기에 시간 절반"(2026-10-25)과 같다.
- 경쟁 방식을 바꾼다: 숨고·크몽 상위 프로필과 싸우는 대신, "석사논문 심사 전 체크리스트" 같은 질문을 검색하는 사람을 직접 만난다.
- 써 보고 믿은 뒤 산다: 무료 글로 신뢰를 먼저 주고, 글 끝에서 서비스로 잇는다.

## 지금 우리 상태 (솔직하게)

| 항목 | 상태 |
|---|---|
| 구글 서치 콘솔 | 아직 등록 안 됨. 그래서 빈틈 검색어 데이터가 없다 |
| 블로그 글 | 3편(면접). 3편째는 작업 브랜치에만 있고 공개 사이트(main)에는 아직 없다 |
| 원고 | 면접 4~10편은 `docs/블로그-글-10편.md`에 이미 써 둠 |
| 사이트 지도·로봇 파일 | 2026-10-29 만듦(`sitemap.xml`, `robots.txt`). 공개하려면 main에 합쳐야 함 |

영상의 방법은 "이미 노출이 쌓인 사이트"에서 시작한다. 우리는 노출이 거의 0이므로, 처음 4주는 데이터를 모으는 기간이다.

## 단계

### 1단계 (오늘, 교수님 5분): 구글 서치 콘솔 등록
1. https://search.google.com/search-console 접속(구글 계정 로그인)
2. 속성 추가 → 오른쪽 **URL 접두어** → `https://ju2497-web.github.io/` 입력
3. 확인 방법 중 **HTML 태그** 선택 → `<meta name="google-site-verification" content="……">` 한 줄 복사
4. 그 한 줄을 Claude에게 보낸다 → Claude가 첫 화면에 넣고 공개 → 교수님이 '확인' 클릭
5. 확인되면 왼쪽 **Sitemaps** → `sitemap.xml` 입력 → 제출

### 2단계 (1~4주): 데이터 모으기
- 이미 써 둔 면접 글 4~10편을 주 3편(월·수·금) 공개한다. 지금(11~12월)이 수시 면접 철이라 검색 수요가 가장 많다.
- 제목은 사람들이 실제로 치는 질문 형태로 바꾼다. 예: "대입 면접 지원동기 답변 예시", "학종 면접 꼬리질문 대비".
- 논문 쪽 첫 글도 시작한다(연중 수요, 11~12월은 학위논문 심사 철). 예: "석사논문 심사 전 체크리스트 20", "심사위원이 연구방법에서 가장 많이 지적하는 것". 글 끝은 숨고·크몽의 논문 정밀진단으로 잇는다(자체 블로그만 링크, 다른 플랫폼은 링크 없이).

### 3단계 (5주 이후): 빈틈 검색어 하나씩
- 서치 콘솔 → 실적 → 검색어 표에서 **노출 많고 순위 20위 밖, 클릭 거의 없는** 검색어를 고른다.
- 처음에는 교수님이 매주 월요일 이 표를 캡처(또는 내보내기)해 올리면 Claude가 그 주의 빈틈 3개를 골라 글을 쓴다.
- 자동화(선택): 서치 콘솔 API용 서비스 계정을 만들어 이 환경의 비밀값으로 넣으면, 예약 작업이 매일 아침 데이터를 직접 읽어 글 초안까지 만든다(이 작업 환경에서 구글 API 주소 접속은 됨을 확인).
- 새 글은 기존에 방문자가 많은 글에서 링크를 걸어 준다.

### 4단계: 공개 방식
- Claude가 초안을 쓰고, 교수님이 "공개"라고 하면 올린다. 교수님 검수 없이 자동 공개하지 않는다(실명 교수 글이고, 구글은 사람이 확인하지 않은 대량 AI 글을 걸러낸다).

## 지킬 것
- 소속 대학명과 그 대학의 전형·문항은 쓰지 않는다.
- 합격 보장·100%·최고, "월 ○○", "○○일 만에" 같은 표현은 쓰지 않는다.
- 국가시험 기출 원문은 쓰지 않는다("임상병리사 국시 조직학 기출문제" 같은 검색어는 원문 없이 개념 해설 글로만).
- 남의 논문·학생 사례는 쓰지 않고 "흔한 예"로만 쓴다.

## 영상의 셋째 교훈(평생 이용권)과 우리
- 신뢰를 파는 상품은 써 보고 믿은 뒤에 산다. 메디컬 사이언스 전자책은 한 번 사면 계속 읽는 '평생 소장형'이라 같은 구조다.
- 정밀진단 환불 보장(2026-10-25 교수님 결정 대기)도 같은 원리다.
