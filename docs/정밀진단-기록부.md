# 정밀진단 기록부 (2026-10-29 시작)

목적: 논문 정밀진단을 할 때마다 한 줄씩 쌓아, "학위논문 심사에서 실제로 무엇이 가장 많이 걸리는가"를 숫자로 말할 수 있게 한다. AI가 6시간이면 사이트는 베끼지만, 이 기록은 베낄 수 없다(TrustMRR 영상 판정, 2026-10-29).

## 규칙

- **익명.** 이름, 학교, 지도교수, 논문 제목, 연구 대상 기관은 적지 않는다. 분야는 대분류까지만(예: 간호, 임상병리, 보건정책, 기초의학).
- **동의.** 진단 안내에 "이름·학교·논문 제목을 지운 통계로만 쓰일 수 있고, 원치 않으면 말씀해 달라"는 문구를 넣는다(숨고 상세 설명에 반영). 원치 않은 의뢰는 '동의' 칸을 N으로 두고 집계에서 뺀다.
- **기록 시점.** 진단 보고서를 보낸 날. Claude가 보고서 초안을 만들 때 한 줄을 같이 채우고, 교수님 최종본에서 바뀐 것을 고친다.
- **걸린 항목.** 진단 보고서의 20개 항목 번호와 심각도(상·중·하)로 적는다. 예: `7상, 12중, 15하`
- **공개.** 10건, 30건이 될 때 집계해서 블로그 글과 상품 설명의 근거로 쓴다. 한 건 한 건의 내용은 공개하지 않는다.
