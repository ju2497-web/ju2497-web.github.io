# 클로드 데스크톱에 도구 5개 연결하기: 받은 안내문 점검 (2026-10-30)

교수님이 보내 주신 유튜브 영상(https://youtu.be/6RNdV6a5gts)은 작업 환경에서 열 수 없어서, 함께 보내 주신 「완전 정복 가이드」를 기준으로 점검했다. 안내문은 클로드 데스크톱 앱의 `claude_desktop_config.json`에 MCP 도구 5개(Playwright, Perplexity, Firecrawl, PostHog, Composio)를 연결하는 방법이다.

## 1. 안내문 그대로 하면 안 되는 곳 (npm 등록 정보로 2026-10-30 확인)

| 도구 | 안내문 | 확인 결과 | 바른 설정 |
|---|---|---|---|
| Playwright | `@playwright/mcp@latest` | 정상(Microsoft 공식) | 그대로 |
| Perplexity | `server-perplexity-ask` | **지원 종료된 패키지** | `@perplexity-ai/mcp-server`, 환경변수 `PERPLEXITY_API_KEY` |
| Firecrawl | `firecrawl-mcp` | 정상 | 그대로 |
| PostHog | `@posthog/mcp` + `POSTHOG_API_KEY` | **다른 물건.** MCP 서버를 만드는 개발자가 자기 서버 사용량을 PostHog로 보내는 SDK다. 클로드에 붙여도 아무것도 안 된다 | 터미널에서 `npx @posthog/wizard@latest mcp add` |
| Composio | `npx @composio/mcp@latest setup` | **지원 종료된 패키지** | 쓰지 않는다(아래 2번) |

3개가 틀렸다. 안내문을 그대로 붙이면 Playwright·Firecrawl만 뜨고 나머지는 오류가 나거나 조용히 아무 일도 하지 않는다.

## 2. 교수님 계정에 이미 있는 것

| 안내문 도구 | 하는 일 | 교수님이 이미 가진 것 |
|---|---|---|
| Composio | Gmail·캘린더·노션 연결 | 클로드 계정에 Gmail, Google 캘린더, Drive, Docs, Sheets, Slides, Notion이 **이미 연결돼 있다**(설정 → 커넥터). 데스크톱 앱에서도 그대로 쓴다 |
| Perplexity | 최신 웹 검색 | 클로드 자체 웹 검색, PubMed 커넥터. 논문 찾기는 PubMed가 더 정확하다. Perplexity API는 유료 크레딧을 쓴다 |
| PostHog | 앱 이용자 분석 | 실험실 앱은 GoatCounter로 정했다(`lab/config.js`, `실험앱-운영규칙.md`). 남은 일은 분석 도구 추가가 아니라 **집계 코드를 넣는 것**이다 |
| Firecrawl | 웹사이트 통째로 읽기 | 클로드의 웹 읽기로 대부분 된다. Firecrawl 무료 크레딧은 적고 이후 유료다 |
| Playwright | 내 PC 브라우저를 클로드가 조종 | 겹치는 것이 없다. 유일하게 새로 생기는 기능이다 |

## 3. 판정: 일부 적용(Playwright 하나만)

- **이 도구들은 돈을 벌어 주지 않는다.** 클로드가 할 수 있는 일을 늘릴 뿐이다. 빚을 갚는 돈은 지금도 손님이 값을 치르는 상품(논문 정밀진단, 이러닝·강의 수주, AI SME 평가)에서 나온다. 도구 연결에 저녁을 쓰기보다 오늘 공고 하나에 지원하는 쪽이 먼저다.
- **연결하는 것: Playwright.** 무료이고 API 키가 필요 없다. 국시원·공고 사이트처럼 로그인이 필요 없는 공개 페이지를 읽고 캡처하는 데 쓴다.
- **연결하지 않는 것**: Composio(지원 종료, 기능 중복), PostHog(엉뚱한 패키지, GoatCounter로 이미 결정), Perplexity·Firecrawl(유료 크레딧, 기능 중복). 나중에 필요하면 위 표의 바른 설정을 쓴다.
- **지킬 것**:
  1. 숨고·크몽·대학 시스템에 Playwright로 자동 로그인하거나 자동 응답하지 않는다. 플랫폼 약관 위반과 계정 정지 위험이 있고, 1:1 맞춤 응대 원칙과도 맞지 않는다(마누스 영상 판정과 같다).
  2. API 키는 교수님 PC의 설정 파일에만 둔다. 이 저장소(공개)나 채팅에 붙여 넣지 않는다.
  3. 안내문의 "기존 내용을 지우고 붙여넣기"는 하지 않는다. 다른 설정이 있으면 함께 지워진다. 아래처럼 `"mcpServers"` 안에 한 덩어리만 더한다.

## 4. 교수님 PC에서 할 일 (10분)

1. nodejs.org에서 LTS 버전 설치(이미 있으면 건너뜀).
2. 클로드 데스크톱 앱 → 설정 → 개발자 → 설정 편집 → `claude_desktop_config.json`을 메모장으로 연다.
3. 파일이 비어 있거나 `{}`만 있으면 아래 전체를, `"mcpServers"`가 이미 있으면 `"playwright": {...}` 덩어리만 그 안에 넣는다(앞 덩어리 뒤에 쉼표).

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    }
  }
}
```

4. 저장 → 클로드 앱을 **완전히 종료**(윈도우는 작업 표시줄 오른쪽 트레이 아이콘 우클릭 → Quit) → 다시 실행.
5. 시험: "플레이라이트로 국시원 누리집에서 임상병리사 국가시험 일정 페이지를 열고 캡처해 줘."

나중에 Perplexity가 꼭 필요해지면 `"playwright": {...}` 뒤에 쉼표를 찍고 아래를 더한다.

```json
    "perplexity": {
      "command": "npx",
      "args": ["-y", "@perplexity-ai/mcp-server"],
      "env": { "PERPLEXITY_API_KEY": "교수님_키" }
    }
```
