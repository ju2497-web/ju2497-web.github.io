# 🍻 회식하는 동물들 (쇼츠 · 인스타툰 시리즈)

직장인의 회식·숙취를 동물 캐릭터로 그린 시리즈. 웃음 포인트는 **과음 자랑이 아니라 후회와 숙취**.

## 완성본 (`out/`)
| 편 | 제목 | 4컷 (인스타 1080×1350) | 쇼츠 (1080×1920, 13초) |
|---|---|---|---|
| 1 | 소맥 황금비율 | `ep1_4cut.png` | `ep1_shorts.mp4` |
| 2 | 다시는 안 마신다 | `ep2_4cut.png` | `ep2_shorts.mp4` |
| 3 | 인생 첫 회식 | `ep3_4cut.png` | `ep3_shorts.mp4` |
| 4 | 딱 한 잔만 | `ep4_4cut.png` | `ep4_shorts.mp4` |
| 5 | 월요일 아침 단톡방 | `ep5_4cut.png` | `ep5_shorts.mp4` |

영상에는 소리가 없다. **업로드할 때 유튜브·인스타 앱에서 유행 음원을 붙이면** 노출에 유리하다.

## 캐릭터
| 캐릭터 | 동물 | 성격 | 단골 대사 |
|---|---|---|---|
| 김대리 | 말티즈 | 소맥 말기 장인, 연애는 늘 실패 | "황금비율 나왔습니다~" |
| 박과장 | 회색 코숏 | 매일 아침 숙취, 매일 저녁 회식 | "다시는 안 마신다…" |
| 막내 햄찡 | 햄스터 | 한 잔에 빨개지고 마이크는 안 놓음 | "앵콜!!" |
| 곰 부장 | 곰 | 회식을 사랑하는 부장님 | "오늘 저녁 회식이다~!" |

## 업로드 문구
- 제목 예: `회식 다음 날 박과장 상태 ㅋㅋ #회식하는동물들 EP.2`
- 설명: `매주 회식하는 동물들의 직장 생활 🍻 과음은 다음 날의 나에게 미안한 일.`
- 해시태그: `#회식 #직장인공감 #숙취 #직장인 #강아지 #고양이 #햄스터 #인스타툰 #쇼츠`
- 순서: 인스타에는 4컷, 유튜브 쇼츠·릴스·틱톡에는 영상

## 다음 대본 (6~10편)
6. **회식 장소 투표** — 곰 부장 "아무 데나~" → 다들 고깃집 제안 → 부장 "음… 거긴 좀" → 결국 매번 같은 포장마차
7. **건배사 지옥** — 막내 햄찡에게 건배사가 돌아옴 → 머리 하얘짐 → "…위하여?" → 박수 터짐
8. **택시 잡기** — 새벽 1시, 김대리 택시 잡기 실패 → 앱 호출 대기 37분 → 편의점 의자에서 잠듦
9. **해장 전쟁** — 박과장 해장국파 vs 김대리 라면파 vs 햄찡 아이스아메리카노파 → 셋 다 실패
10. **금주 선언 D+1** — 박과장 "이번 달 금주!" → 다음 날 곰 부장 생일 회식 공지 → 무표정 → "…생일은 예외"

`episodes.js`에 같은 형식으로 추가하고 다시 뽑으면 된다.

## 다시 뽑는 법
```
NODE_PATH=$(npm root -g) node shorts/render.js            # 전체
NODE_PATH=$(npm root -g) node shorts/render.js ep6         # 한 편만
NODE_PATH=$(npm root -g) node shorts/render.js --comic-only  # 4컷만
```
- 캐릭터·소품·배경: `characters.js` / 대사·장면: `episodes.js` / 화면 구성·움직임: `studio.html`, `studio.js`
- 필요: Node, Playwright(Chromium), ffmpeg
