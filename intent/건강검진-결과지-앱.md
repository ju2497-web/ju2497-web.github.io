# 건강검진 결과지 읽어 주는 앱

## 무엇을 하나
건강검진 결과지의 숫자를 넣으면, 항목마다 무엇을 재는 검사인지, 내 숫자가 공단 판정 기준의 어느 구간에 있는지를 쉬운 말로 보여 준다. 작년 숫자와 나란히 놓고, 진료실에서 의사에게 물어볼 질문 3개를 뽑아 준다. 보건계열 현직 교수(필명 '강교수')가 검사 수치를 직접 감수한다는 점이 다른 앱과 다른 점이다. 2026-10-30 교수님 승인.

## 빈틈 한 줄 (1단계 조사 결과)
"사진을 서버로 보내지 않고, 검사실 전문가가 확인한 설명으로, 진료실에서 물어볼 말까지 정리해 주는 무료 웹앱"은 아직 없다.

| 서비스 | 하는 것 | 못 하는 것 |
|---|---|---|
| The건강보험 앱·건강iN(공단) | 결과 조회, PDF 출력, 과거 결과 비교, 건강나이·질병위험 예측 | 항목별 쉬운 말 설명이 짧고, "그래서 무엇을 물어보나"가 없음. 공단 검진만 다룸 |
| 체크업+ | 공단 결과 10년치 불러오기, 대사증후군 항목 그래프, 건강나이 | 본인인증·앱 설치 필요, 설명보다 예측 중심 |
| 온톨 | 결과지 사진을 올리면 AI가 쉬운 말로 설명 | 사진·건강정보가 업체 서버로 감. 사진 상태에 따라 글자 인식 오류 |
| Wizey(해외) | 혈액검사 문서 AI 분석, 여러 날짜 추이 그래프 | 국내 공단 판정 기준(정상A·정상B·질환의심)과 맞지 않음, 유료 |
| 착한의사 등 검진기관 앱 | 검진 예약·비교·결과 조회 | 해석은 거의 없음 |

## 범위
- 하는 것: 공단 일반건강검진 항목(혈압, 공복혈당, 총콜레스테롤·HDL·LDL·중성지방, AST·ALT·γ-GTP, 혈색소, 크레아티닌·eGFR, 요단백, BMI·허리둘레)의 숫자 입력 → 구간 표시와 쉬운 말 설명 → 작년과 비교 → 의사에게 물어볼 질문 3개
- 나중에 검토: 결과지 사진에서 숫자 읽기(기기 안에서만 처리할 수 있을 때만), 종합검진 추가 항목
- 하지 않는 것: 진단("당뇨입니다"), 처방·약 이름 권유, 건강나이·질병확률 예측, 특정 병원·제품 권유, 서버에 건강정보 저장, 회원가입

## 누가 쓰나
검진 결과지를 받고 "공복혈당 108인데 괜찮나요?"를 커뮤니티에 묻는 30~60대 성인과, 부모님 결과지를 대신 읽어 드리는 자녀.

## 지킬 제약
- 의료기기가 아닌 쪽에 머문다. 식약처 기준은 사용목적으로 가른다(질병의 진단·치료·예방 목적이면 의료기기). 그래서 화면 문구는 "공단 판정 기준으로 이 구간입니다 / 이 구간이면 병원에서 상의하세요"까지만 쓰고, 모든 화면에 "이 앱은 질병 유무를 판단하지 않습니다. 진단은 의사의 진찰이 필요합니다"를 둔다.
- 건강정보는 개인정보 보호법 제23조의 민감정보다. 처리하려면 별도 동의가 필요하므로, 아예 우리가 처리(수집·저장·전송)하지 않는 구조로 만든다: 입력값은 브라우저 안에서만 계산하고, 작년 기록은 사용자 기기(localStorage)에만 둔다. 분석 도구·광고 스크립트를 붙이지 않는다.
- 설명 문구는 교과서·학회 진료지침·공단 판정 기준으로 확인한 것만 쓰고, 항목마다 출처를 단다. 확인 못 한 기준치는 넣지 않는다.
- 비용 0원: GitHub Pages, 외부 서버·유료 API 없음.
- 공개 화면에는 '강교수 / 보건계열 현직 교수'만 쓴다.

## 성공 기준
- 2026-11-20까지 첫 판 공개(항목 12개 이상, 출처 표기 완료)
- 공개 후 4주 안에 블로그 글 1편에서 연결, 앱 화면에서 "도움이 됐나요" 대신 블로그 구독·전자책 소개 클릭 수로 반응 확인(서버 없이 볼 수 있는 GitHub Pages 트래픽과 블로그 지표만 사용)
- 수익 기대치: 앱 자체로는 0원. 역할은 신뢰를 쌓아 블로그·전자책·강의 문의로 잇는 입구다. 앱만으로 이자 부담을 덜 수 있다고 약속하지 않는다.
