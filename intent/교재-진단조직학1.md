# 판매용 교재 「진단조직학 1」

## 무엇을 하나
교수님이 가르치는 진단조직학(조직검사학) 전반부를 학생이 혼자 읽고 공부할 수 있는 교재로 만든다. 학생들은 지금 강의록(슬라이드)만 보므로, 강의록의 순서와 내용을 뼈대로 삼아 교재로 읽힐 만큼 설명을 채운다. 교재 시리즈(진단조직학 1·2, 진단세포학, 병리학, 조직학, 뒤에 임상유전학·임상병리학개론)의 첫 권이다.

## 범위
- 하는 것: 1~8장, 조직검사학 개요부터 일반 염색(H&E)까지. 장마다 학습목표 → 본문(그림·표) → 핵심 정리 → 확인 문제(새로 쓴 문항, 정답·해설).
- 하지 않는 것: 뼈조직·탈회, 특수염색(진단조직학 2로 보냄). 국가시험 기출 원문 수록. 다른 출판사·인터넷 그림 사용.

## 누가 쓰나
보건계열(임상병리학) 학생, 국가시험을 준비하는 사람

## 지킬 제약
- 근거의 중심은 교수님 강의록. 출판된 조직검사학 교재는 사실 확인과 보충에만 쓰고 문장을 옮기지 않는다. 교재와 강의록이 다르면 교재를 따르고, 다른 곳은 목록으로 교수님께 보고한다.
- 그림은 교수님이 직접 찍은 표본 사진과 새로 그린 도식만 쓴다. 출처가 불분명한 그림은 빼고 목록으로 보고한다.
- 결과물은 Word(docx) 출판 원고. 학술적인 문체, 이모지 없음.
- 교재 파일·강의록·사진은 이 공개 저장소에 올리지 않는다. 원고는 교수님께 파일로 직접 보낸다.
- 국시 문제은행 앱의 조직검사학 챕터와 용어를 맞춘다(확인 문제와 앱 문제를 함께 쓰기 위해).

## 성공 기준
- 1장 샘플을 교수님이 형식·문체 확인
- 8장 원고 완성 후 전자책 판매 사이트에 등록(판매는 '전자책 출판소' 세션이 맡는다)

## 바뀐 결정
- 2026-10-31 시작(교수님). 범위는 1~8장, H&E까지. 뼈조직은 진단조직학 2로.
- 2026-10-31 교수님 지시: 강의록에 없는 내용은 새로 넣지 않는다. 강의록에 실린 국가시험 기출 문항이 다루는 개념을 기준으로 본문 비중과 확인 문제를 정한다(문항 원문은 싣지 않고 새로 쓴다). 그래서 강의록에 없는 '현미경' 장은 두지 않고, 강의 순서(개요·종류 → 검체와 절취 → 고정 → 탈수·투명·침투 → 포매 → 박절 → 염색 이론 → H&E)대로 8장을 짠다.
- 2026-10-31 판형·조판은 같은 시리즈의 병리학·임상병리학개론 교재와 맞춘다: 4×6배판(188×257 mm), 본문 맑은 고딕, 평서체, DOCX → PDF → EPUB, 판매는 학생별 워터마크 PDF.
- 2026-10-31 교수님 지시: 교재 수준으로 다시 쓴다. 강의록에 실린 그림·모형·표와 출판 교재(조직검사학)의 그림·표를 모두 쓴다(교재 판권은 교수님 소유). 강의록을 중심으로 교재 내용을 붙인다. 다른 회사·누리집 표시가 보이는 그림은 넣되 판매 전 확인 목록으로 따로 드린다. 자료는 드라이브로는 그림을 받을 수 없어 대화창에 직접 올려 받는다.
- 2026-10-31 원고 진행: 3·4·6·7·8장 완성(77쪽, 그림 약 50장). 1·2·5장은 강의록을 받으면 쓴다.
