입시 문의 자동답변

○○대학교 입학처 · 수시/정시 상담 답변 작성 도구

모집 일정·연락처가 아직 비어 있습니다. 설정에서 우리 대학 정보를 입력하면 답변에 자동 반영됩니다.

문의 내용

매칭된 답변 항목 체크를 바꾸면 답변이 다시 조립됩니다

    답변 초안

    일괄 처리

    문의를 한 줄에 하나씩(여러 줄 문의는 --- 줄로 구분) 붙여 넣거나, 첫 열이 문의 내용인 CSV 파일을 불러오세요. 결과는 CSV(엑셀)로 내려받을 수 있습니다.

    #문의분류매칭 항목답변

    지식베이스

    답변에 {{대학명}}, {{수시원서접수}}처럼 쓰면 [설정] 값으로 자동 치환됩니다. 키워드는 쉼표로 구분하며, 띄어쓰기는 무시하고 비교합니다.

    대학·모집 정보

    여기 입력한 값이 모든 답변의 {{변수}}에 들어갑니다. 비워 두면 답변에 “설정 필요”로 표시되어 발송 전에 알 수 있습니다.

    AI 다듬기 (선택)

    Claude API 키를 입력하면 [AI로 다듬기]로 지식베이스에 근거한 자연스러운 답변을 받을 수 있습니다. 키는 이 브라우저에만 저장되고 Anthropic API로만 전송됩니다. 공용 PC에서는 사용 후 키를 삭제하세요.

    작동 방식

    1. 문의에서 전형(수시/정시)과 질문자(학생/학부모)를 판별합니다.
    2. 키워드·문장 유사도로 지식베이스의 승인된 답변을 최대 3개 고릅니다.
    3. 채널(이메일·게시판·카톡·전화)에 맞춰 인사말·본문·유의사항·서명을 조립합니다.
    4. AI 사용 시, 같은 지식베이스만 근거로 문장을 다듬고 근거 없는 수치는 쓰지 않도록 지시합니다.

    답변 기록

    기록은 이 브라우저에만 저장됩니다. 자주 쓰는 답변은 FAQ 통계로 활용해 지식베이스를 보강하세요.
