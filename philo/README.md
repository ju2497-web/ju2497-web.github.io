# 마흔의 철학 한 줄 (쇼츠)

40~60대를 겨냥한 철학 명언 쇼츠. 원전 인용 → **교수의 한 줄 해석** → 구독 유도. 약 18~20초, 세로 1080×1920.

| 편 | 문장 | 파일 |
|---|---|---|
| 1 | 인생의 처음 40년은 본문, 나머지 30년은 주석 | `out/ep1_shorts.mp4`, `out/ep1_cover.png` |
| 2 | 남들처럼 되려고 자기 자신의 4분의 3을 잃는다 | `out/ep2_shorts.mp4`, `out/ep2_cover.png` |
| 3 | 고독을 사랑하지 않는 사람은 자유도 사랑하지 않는다 | `out/ep3_shorts.mp4`, `out/ep3_cover.png` |

- 인용문은 쇼펜하우어 원전(1851, 퍼블릭 도메인)을 직접 옮긴 번역. 시중 책의 번역문·제목을 그대로 쓰지 않는다.
- 영상에 소리가 없다. 업로드할 때 앱에서 잔잔한 피아노 음원을 붙이거나, 교수님 목소리로 녹음해 얹는다(가장 강력한 차별점).
- 문장 추가: `quotes.js`에 같은 형식으로 넣고 `NODE_PATH=$(npm root -g) node philo/render.js ep4`
- 다음 후보: 부는 바닷물과 같다(마실수록 목마르다) / 우리는 가진 것은 생각하지 않고 없는 것만 생각한다 / 재능은 남이 못 맞히는 과녁을, 천재는 남이 못 보는 과녁을 맞힌다
