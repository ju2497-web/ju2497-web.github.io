# 강의 상세페이지 (와디즈형)

- 웹 페이지: `course/index.html` (공개 후 `https://ju2497-web.github.io/course/`)
- 플랫폼 업로드용 이미지: `course/detail/detail_01~06.jpg` (가로 864px, 2000px 단위로 자름)

## 올리기 전에 바꿀 것
1. 강사 이름 `OOO 교수` → 실제 이름
2. 가격(정가 149,000원 / 얼리버드 69,000원)과 "선착순 100명" — 정한 대로. **선착순 약속은 실제로 지켜야 한다.**
3. 구매 버튼 링크 `#buy` → 클래스101·인프런·크몽 상품 주소 (두 곳: 가격 상자, 하단 고정 바)
4. 환불 문구 → 올리는 플랫폼 규정

## 이미지 다시 뽑기
페이지를 고친 뒤 Playwright로 `course/index.html#render`를 폭 720px 전체 화면 캡처 → 2000px씩 자르기.
글꼴(Noto Sans KR)은 `course/fonts/`에 로컬로 두고 쓰며 저장소에는 올리지 않는다(웹에서는 구글 폰트로 표시).
