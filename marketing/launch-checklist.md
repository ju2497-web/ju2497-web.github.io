# 출시 체크리스트: 교수님이 직접 하셔야 하는 것

AI가 만든 것: 전자책 원고와 PDF(`book/`), 판매 페이지(`book.html`), 가격 설정(`js/book-config.js`), 홍보 글 10개, 상담소 답변 틀, 운영 매뉴얼(`CLAUDE.md`).
AI가 할 수 없는 것: 계정 만들기, 결제 받기, 신고, 규정 확인. 아래는 전부 교수님 명의로 직접 하셔야 합니다.

## 0. 먼저 확인 (출시 전, 30분)
- [ ] **저장소 공개 여부.** 이 저장소가 공개(public)이면 `book/manuscript.html`과 PDF가 인터넷에 그대로 노출됩니다. 판매 전에 둘 중 하나를 하세요.
  - `book/` 폴더를 비공개 저장소나 내 컴퓨터로 옮기고 이 저장소에서 삭제
  - 또는 저장소 자체를 비공개로 전환(GitHub Pages 유지에는 유료 플랜이 필요할 수 있음)
- [ ] **학교 겸직·외부 수입 규정.** 전자책 판매와 유료 코칭이 교원 복무 규정에 걸리는지 확인. 입학처장 직위와의 이해충돌 여부도 함께. 소속 대학 지원자 배제 원칙은 책과 페이지에 이미 써 두었습니다.
- [ ] **원고 검수.** `book/manuscript.html`을 처음부터 끝까지 읽고 교수님 기준과 다른 문장을 고치세요. 특히 채점표 배점과 "현직 입학처장" 표현이 실제와 맞는지. 고친 뒤 `node book/build.mjs`로 PDF를 다시 만듭니다.

## 1. 판매 플랫폼 (1시간)
- [ ] 전자책 판매처 하나 선택: 크몽(전자책 카테고리), 래피드, 또는 자체 결제(스마트스토어·페이앱). 크몽은 심사가 있고 수수료가 있지만 유입이 있습니다.
- [ ] 상품 등록: 제목 "면접관은 이렇게 듣는다", 부제, 분량 A4 24쪽, 상세 설명은 `book.html` 본문을 그대로 옮기면 됩니다.
- [ ] **환불 규정**은 플랫폼 원문을 복사해서 그대로 쓰세요. 영상에서 AI가 틀린 부분이 정확히 이것입니다. "열람 후 환불 불가"가 가능한지 플랫폼마다 다릅니다.
- [ ] 상품 URL을 `js/book-config.js`의 `buyUrl`에 넣고, 문의처를 `contact`에 넣습니다.

## 2. 사업자·세금 (플랫폼에 따라)
- [ ] 크몽 등은 개인 판매자로도 시작할 수 있지만, 계속 팔면 **사업자등록과 통신판매업 신고**가 필요합니다. 세무사나 홈택스 상담으로 확인하세요.
- [ ] 수입은 종합소득세 신고 대상입니다.

## 3. 가격 규칙 운영 (매일 5분)
- [ ] 시작 가격 19,000원, 1권마다 +1,000원, 초판 100부 한정. 바꾸려면 **판매 시작 전에** `js/book-config.js`에서 바꾸세요. 시작 후에는 공지한 규칙을 지켜야 합니다.
- [ ] 매일 플랫폼 주문 수를 보고 `sold` 값을 같게 갱신하고 플랫폼 상품 가격도 같이 올립니다. **실제 주문 수보다 많게 적지 마세요.** 허위 표시는 표시광고법 문제가 됩니다.
- [ ] 100부가 끝나면 `sold`를 100으로 두고(페이지가 "초판 마감"으로 바뀜) 2판 가격을 따로 정합니다.

## 4. 홍보 (매일 20분)
- [ ] 스레드 계정 하나(없으면 인스타 계정으로 로그인). 첫날 `marketing/threads-posts.md`의 1번, 2번 글을 올리고 링크는 댓글에.
- [ ] 2일차부터 하루 1~2개. 9번 "고민 상담소" 글이 가장 중요합니다. 들어오는 질문에는 `consult-templates.md`로 당일 답변.
- [ ] 수험생·학부모 카페(수만휘, 오르비, 지역 맘카페)는 홍보 규정이 엄격합니다. 상담 글만 올리고 링크는 요청받을 때만 DM으로.
- [ ] **수익 인증 글은 올리지 않습니다.** 판매 수량은 가격 안내 글(8번)에서 실제 수치만.

## 5. 숫자로 보는 목표 (한 달)
| 항목 | 목표 | 매출 |
|---|---|---|
| 전자책 초판 100부 (19,000→118,000원, 평균 68,500원) | 100부 완판 시 | 약 685만 원 |
| 전자책 30부만 팔릴 때 (평균 33,500원) | 현실적 하한 | 약 100만 원 |
| 면접답변 제작 정밀형 49,000원 | 전자책 구매자의 10%가 전환 | 30부 기준 약 15만 원, 100부 기준 약 49만 원 |

30부도 보장되지 않습니다. 영상의 결과는 팔로워가 이미 있는 채널에서 나온 것이고, 교수님 채널은 0에서 시작합니다. 첫 주 판매가 5부 미만이면 가격보다 **유입**이 문제이므로 상담소 글 빈도를 늘리고, 10일이 지나도 10부 미만이면 주제나 제목을 바꿉니다.

## 6. 매일 아침 루틴 (AI에게 시킬 것)
`CLAUDE.md`에 적어 두었습니다. 새 세션을 열고 "오늘 운영 루틴 돌려"라고 하면 됩니다.
1. 어제 판매 수를 물어보고 `sold` 갱신 제안
2. 오늘 올릴 홍보 글 1개 선택·수정
3. 들어온 상담 질문에 답변 초안
4. 제작 서비스 문의가 있으면 `soomgo.html`/`apply.html` 흐름으로 견적 문안
