# 입시 문의 자동답변

수험생·학부모의 수시/정시 입시 문의를 붙여 넣으면, 대학이 승인한 지식베이스를 바탕으로
이메일·Q&A 게시판·카카오톡·전화 스크립트 형식의 답변 초안을 자동으로 작성하는 입학처용 웹앱입니다.
서버 없이 GitHub Pages에서 바로 동작합니다.

## 주요 기능
- **답변 작성**: 전형(수시/정시)·질문자(학생/학부모) 자동 판별 → 관련 답변 최대 3개 매칭 → 채널·어조별 답변 조립. 매칭 항목은 체크박스로 넣고 뺄 수 있음.
- **담당자 메모 → 완성 답변**: 핵심만 한 줄씩 적으면("교과·종합 동시 지원 가능", "작년 예비 18번까지 충원") 존댓말 완성 문장으로 다듬어("가능합니다.", "충원되었습니다.") 답변 맨 앞에 넣고, 지식베이스 답변은 보충 안내로 붙임.
- **진정성**: 문의 내용에서 상황(실수·결과 대기·재도전·불안·검정고시·적성 고민·학부모)을 읽어 그에 맞는 공감 첫 문장과 응원 맺음말을 자동으로 넣음.
- **차별화**: [설정 → 강점]에 `태그,태그: 문장` 형식으로 우리 대학·학과 자랑을 적어 두면 문의와 관련된 강점을 골라 덧붙임(임상병리학과 예시 제공). `○○`가 남아 있으면 발송 전 경고.
- **일괄 처리**: 여러 문의를 한 번에 처리하고 CSV(엑셀)로 내려받기. 미매칭 문의는 "담당자 확인 필요"로 표시.
- **지식베이스**: 수시·정시·공통·학과(임상병리학과 예시) 31개 기본 항목. 추가/수정/삭제, JSON 내보내기·가져오기.
- **설정**: 대학명, 모집 일정, 연락처를 한 번 입력하면 모든 답변의 `{{변수}}`에 자동 반영(조사 은/는·이/가 자동 처리). 비어 있는 값은 발송 전 경고.
- **AI 다듬기(선택)**: 본인 Claude API 키를 넣으면 같은 지식베이스만 근거로 자연스러운 문장으로 다듬음. 키는 브라우저에만 저장.
- **기록**: 저장한 답변 기록·자주 묻는 항목 통계·CSV 내보내기.

## 실행
- 배포: 저장소 Settings → Pages에서 기본 브랜치를 지정하면 `https://ju2497-web.github.io/`에서 사용.
- 로컬: `python3 -m http.server` 후 `http://localhost:8000` 접속(ES 모듈이라 파일 더블클릭으로는 동작하지 않음).

## 파일 구성
- `index.html`, `css/style.css` — 화면
- `js/kb.js` — 기본 지식베이스·설정값·예시 문의
- `js/engine.js` — 문의 분석과 답변 조립
- `js/ai.js` — Claude API 연동(선택)
- `js/app.js` — 화면 동작과 저장

> 모든 답변은 일반 안내이며, 최종 기준은 해당 학년도 모집요강입니다. 발송 전 담당자 검토를 권장합니다.

# 면접 대비 노트 (`interview.html`)

대학이 공개한 면접 문항을 넣으면, 학생 본인의 경험 재료로 문항별 답변 초안을 만들고 실전처럼 연습하는 앱입니다.

1. **① 면접 문항** — “면접 문항을 주세요.” 공개 문항을 붙여 넣으면 번호(1. / Q1 / ①) 기준으로 나누고 유형(지원동기·활동·공동체·윤리·장단점·진로·전공·독서·시사·마지막 한마디)을 자동 판별합니다.
2. **② 나의 재료** — 지원 계기, 대표 활동(한 일·배운 점), 장단점, 갈등 경험, 책 등을 짧게 적으면 문장으로 다듬어 답변에 넣습니다. 재료가 없으면 `[✎ …]` 빈칸 뼈대로 만듭니다.
3. **③ 답변 노트** — 문항별 답변(수정 가능·자동 저장), 말하기 시간, 핵심 키워드 3개, 예상 꼬리질문, 평가 포인트, 블라인드 위반(학교명·가족 직업·이름) 경고. 전체 복사·텍스트 저장·인쇄, 선택적 AI 다듬기(재료에 없는 경험은 만들지 않음).
4. **④ 실전 연습** — 면접관 음성으로 질문 듣기, 제한 시간 타이머, 키워드만 보기, 무작위 꼬리질문, 셀프 체크.

# AI 면접 코치 (`coach.html`) — 대학 면접 답변 AI 생성 + 교수 최종검수 MVP

학생 흐름: 대학 → 학과 → 전형·연도 → 공개 문항 선택 → 문항 유형별 경험 입력 → **[내 면접답변 만들기]** → 예상 점수·문제점 3개·평범한 답변 대비·차별화 답변·꼬리질문·말하기 대본·코칭 → 보관함 → **[교수 최종검수 신청]**

- **교수 평가 프레임**(`js/coach/framework.js`): 문항 유형 10종별 질문 의도·평가역량·면접관이 보는 것·경험 추출 질문·평범한 답변 예시·꼬리질문과 답변 방향, 평범한 표현 판별 기준. 서비스의 핵심 자산.
- **기본형**(`js/coach/engine.js`): 서버 없이 즉시 동작. 100점 채점(질문 요구 충족 20·두괄식 10·구체성 20·성찰 15·전공 연결 15·진정성 10·시간 10, 블라인드 위반 -15), 목표 시간 맞춤, 말하기 대본.
- **AI 심층형**(`js/coach/prompt.js` + `server/`): ①질문 의도 → ⑩말하기 대본 10단계를 JSON 스키마로 생성. 키는 서버에만 보관(`server/README.md`).
- **문항 DB**(`data/questions.json`, 관리 화면 `coach-admin.html`): 대학·학과·전형·연도·출처별 공개 문항.
- **운영 설정**(`js/coach/config.js`): 가격, 베타 무료, 서버 주소, 검수 신청 이메일, 이해충돌 차단 대학.

## 면접답변 제작 신청서(`apply.html`)와 교수 작업실(`studio.html`)

- **신청서(학생용, 약 5분)**: 고정 7개 필드 — 지원정보 / 공개문항(DB에 있으면 자동 불러오기) / 학생자료(정밀형부터) / 전공지원 이유 / 대표경험 3~5개(분류 칩 + 사실 메모) / 나의 강점 / 특별 요청. “문장을 쓰려고 하지 말고 실제 있었던 경험만” 받습니다. 완성하면 메신저로 보내기 쉬운 **신청 코드(IVAPP1:…)**가 나옵니다.
- **작업실(교수용)**: 신청 코드를 붙여 넣으면 문항마다 맞는 경험을 자동 배정하고, 짧은 메모를 상황 → 문제 → 예상과 다른 사실 발견 → 행동 → 결과 → 배운 점으로 재구성합니다. 메모에 없는 내용은 지어내지 않고 `[✎ …]`로 남깁니다. 문항별·전체 AI 심층 생성, 교수 총평, 검수 완료 표시, 학생 전달 문서(txt·인쇄) 출력. [학생에게 보낼 안내문 복사] 버튼 포함.

## 숨고 응답기(`soomgo.html`)

숨고 요청을 붙여 넣으면 보냄·보류·거절을 판정하고(허위 경험 요청·이해충돌 대학은 거절, 면접 임박·정보 부족은 보류), 대학·학과·면접일을 반영한 맞춤 견적, 고용 후 ①~⑦ 자료 요청, 미열람 후속 1회, 자주 묻는 질문 답변을 만듭니다. 숨고의 외부 링크 제한 때문에 모든 과정이 채팅 안에서 끝나며, 학생의 ①~⑦ 답장은 작업실에 그대로 붙여 넣으면 신청서로 바뀝니다. 견적 캐시 대비 손익분기 성사율과 실제 성사율 기록을 보여 줍니다. 상품·가격·전달 시간은 `js/coach/config.js`의 `soomgo`에서 바꿉니다.
