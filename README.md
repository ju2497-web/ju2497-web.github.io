## Revenue Agent
고단가 수익 기회(국제기구 SME·이러닝·AI 전문가·전문가 자문·공공 평가위원)를 매일 찾아 점수화하고,
오늘 지원할 기회와 다음 행동을 한국어 대시보드로 보여 주는 시스템입니다.

- 대시보드: [`revenue/`](revenue/index.html) (main 병합 후 https://ju2497-web.github.io/revenue/)
- 사용법·구조·설정: [REVENUE_AGENT.md](REVENUE_AGENT.md)
- 빠른 실행: `python -m revenue_agent run`
